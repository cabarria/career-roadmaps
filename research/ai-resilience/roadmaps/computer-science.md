## Current evidence

Coding assistants/agents are widely reported among global developer-survey respondents. The 2025 survey's 84% is using OR planning to use. In contrast, METR's early-2025 randomized work on mature repositories found 19% longer task completion; its 2026 update is suggestive of gains but selection makes magnitudes weak. Code generation is not end-to-end system ownership. Payroll evidence suggests younger workers in exposed occupations face pressure, but pre-ChatGPT trends undermine simple causal claims.

## 2029–31 conditional scenario

By 2029–31 agents may execute larger scoped changes and routine tests within secured repositories. Demand for software could expand as cost falls; firms could also employ smaller junior teams. Integration, data, test quality, review and incident responsibility constrain deployment. Infrastructure and security work remain distinct from greenfield code generation.

This scenario assumes approved data access, higher agent reliability on bounded workflows, and human review appropriate to risk. A slower rollout preserves more manual work; faster adoption could compress routine junior tasks. Neither establishes employment probabilities.

## Student preparation

- Implement and explain a project without AI, then compare AI-assisted time and defects.
- Practice requirements, test design, code review and service monitoring.
- Seek internships with real users and maintained systems, not just generated demos..
