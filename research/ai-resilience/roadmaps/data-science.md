# Data Science: AI resilience

Evidence cutoff **2026-11-25** · United States · scenario horizon **2029–31**.

## Featured occupation

**Data scientists** — stable career ID `data-scientists`; BLS 2025 National Employment Matrix `15-2051`.

Matrix code includes O*NET data scientists, BI analysts and clinical data managers; no component employment weights.

**O*NET-SOC 2019 matches (release 31.0):** 15-2051.00 Data Scientists; 15-2051.01 Business Intelligence Analysts; 15-2051.02 Clinical Data Managers.

**Labor context (not AI's effect):** 275,600 jobs in 2025; +34.6% projected change, 2025–35; 24,800 average annual openings ([BLS Table 1.2, row 15-2051](https://www.bls.gov/emp/tables/occupational-projections-and-characteristics.htm)).

## Current evidence

Global developer responses and Claude usage show code and analysis assistance, not a data-scientist adoption rate. Query and visualization drafts can be cheap; the value of experimental design, data lineage, privacy and decision relevance is not measured by speed of generating code. The matrix includes BI and clinical data occupations with different workflows. A 2026 AgentDS challenge across six industries found the best results in human–AI teams, while AI-only baselines performed around or below the participant median. This is a competition benchmark, not observed time savings or US labor demand.

## 2029–31 conditional scenario

Agents may increasingly self-serve simple analysis from governed data. This could compress routine analyst tasks while increasing demand for reliable data systems and evaluation. Poor definitions and inaccessible data prevent automation; high-stakes domains require additional review.

This scenario assumes approved data access, higher agent reliability on bounded workflows, and human review appropriate to risk. A slower rollout preserves more manual work; faster adoption could compress routine junior tasks. Neither establishes employment probabilities.
