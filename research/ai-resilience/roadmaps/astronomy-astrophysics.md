## Current evidence

Rubin's operational alert brokers filter and classify large observation streams using mostly conventional ML, which is distinct from GenAI. LLMs can assist with data code, documentation and paper drafts, while astronomers set questions, select observations, validate models and interpret surprising events. Wiley's global research survey supports broader adoption, not astronomer-specific prevalence.

**Independent sources:** [Alerts and brokers](https://rubinobservatory.org/for-scientists/data-products/alerts-and-brokers), [ExplanAItions 2025–2026: Evolution of AI in Research](https://www.wiley.com/en-us/about-us/ai/study), [Accelerating Mathematical and Scientific Discovery with Gemini Deep Think](https://deepmind.google/blog/accelerating-mathematical-and-scientific-discovery-with-gemini-deep-think/).

## 2029–31 conditional scenario

Agents could handle more routine pipeline preparation and literature retrieval, increasing the science per researcher. Data abundance may create new work, but telescope access, grants, observatory staffing and positional scarcity—not tool performance alone—determine demand. Junior researchers need independent error detection and instrument context.

This scenario assumes approved data access, higher agent reliability on bounded workflows, and human review appropriate to risk. A slower rollout preserves more manual work; faster adoption could compress routine junior tasks. Neither establishes employment probabilities.

## Student preparation

- Learn statistics and reproducible Python using public archival observations.
- Compare model classifications with independently verified labels and uncertainties.
- Pursue observing/instrumentation or interdisciplinary internships alongside theory..
